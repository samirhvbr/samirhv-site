# S essencial — reserved concept

Refined from option 03 in the original ShvIA exploration on 2026-09-16, at the owner's request. This is a **parked concept for samirhv**, not the active site identity. No production templates or public assets reference this directory.

The continuous diagonal, squared terminals and restrained outside curves form a solid S. Cyan `#34B3EC` and deep navy `#0B0F17` retain the selected reference palette, without glow or gradients.

## Files

- `symbol.svg` and `symbol.png`: standalone mark.
- `symbol-monochrome.svg`: one-color version using currentColor.
- `logo-on-dark.svg` / `logo-on-light.svg`: optional samirhv lockups with transparent backgrounds, also exported as PNG. Wordmark text stays editable in Arial Bold.
- `app-icon.svg` and PNG exports at 192, 512 and 1024 pixels: icon concept.
- `favicon.svg`, PNG exports at 16, 32, 48 and 180 pixels, and `favicon.ico`: compact silhouette on a 16-pixel grid.
- `preview.svg` / `preview.png`: presentation board; Portuguese captions are owner-facing design copy.
- `references/initial-concepts.png`: unchanged source reference; option 03 is the selected direction.
- `export.cjs`: reproducible SVG/PNG export, requiring Node and sharp through NODE_PATH. It writes only into this concept directory.

The ICO contains the supplied 16, 32 and 48 pixel PNGs. The SVGs are original editable geometry, not a crop or a raster embedded in a vector wrapper.
